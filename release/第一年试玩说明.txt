《吗喽森林：家园守卫战》第一年试玩版

运行：双击 monkey_forest_first_year.exe

推荐流程：
1. 输入 talk 岩背，与猴王交谈。
2. 输入 go east，前往果实森林；主线会自动触发。
3. 直接输入 1、2 或 3 选择树冠试炼路线。
4. 若选择1，将进入野蜂战斗，可输入攻击、防御或偷窃。
5. 击败野蜂后再次输入1，完成第一年。

常用命令：
- look / map / guide：查看场景、地图和任务。
- talk 闪尾：与NPC交谈；只有一个NPC时可直接输入talk。
- take：拾取当前场景全部物品。
- take fruit：拾取指定物品。
- bag：查看背包。
- save / load：存档和读档。
- help：查看完整命令。

界面要求：建议使用Windows Terminal，窗口至少120列宽。

# 第一年度双栏UI试玩版整合说明

- 2号 `member-2-story`：`0ca7a58`，采用事件工厂、第一年树冠试炼和剧情文本。
- 3号 `member-3-npc-combat`：`90b5763`，采用NPC、战斗及成就/结局收集系统。

## 试玩版行为

- 固定120列双栏UI：左栏游戏记录，右栏地图/状态/任务/命令，底部输入。
- 第一年度主线限定为“树冠试炼”；进入果实森林时自动触发。
- 事件和NPC出现选项时直接输入数字，不使用`talk NPC 2`。
- NPC任务统一通过`talk`取得和提交，不公开`quest`、`finish`。
- `take`拾取当前房间全部物品，`take fruit`等拾取单件并记录标准物品ID。
- 中文名和英文名均可用于NPC、物品和常用命令。
- 第一年度可选择战斗、攀爬或观察路线；完成后显示试玩结算。
- 存档、状态、地图、背包、成就与结局收集接口均已接入主循环。

## 联调修正

- 1号动态地图保留豆豆/闪尾任务完成后的消失逻辑。
- 4号物品别名统一转换成标准ID后再设置拾取旗标，避免重复拾取。
- 4号主循环支持3号裸数字NPC选项、闪尾邀请及香蕉选项的优先路由。
- 2号主线在玩家抵达目标房间后自动触发，避免重复输入`investigate`。
- 5号读档完成后调用3号`syncLegacyFlags`补录旧成就和结局。

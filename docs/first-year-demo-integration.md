# 第一年度双栏 UI 试玩版整合说明

## 整合基线

当前工程采用各成员模块的以下版本：

- 1号：最新动态地图、可见 NPC/物品和地图命令。
- 2号：事件工厂、第一年树冠试炼和剧情文本。
- 3号：NPC、战斗及成就/结局收集系统。
- 4号：玩家、物品、批量拾取与背包逻辑。
- 5号：世界状态、进度、存读档和结局判定。

## 试玩版行为

- 地图采用坐标渲染，布局、测试和运行限制见[坐标 UI 接入说明](coordinate-ui-integration.md)。
- 第一年度主线限定为「树冠试炼」，进入果实森林时自动触发。
- 事件和 NPC 出现选项时直接输入数字，不使用 `talk NPC 2`。
- NPC 任务统一通过 `talk` 取得和提交，不公开 `quest`、`finish`。
- `take` 拾取当前房间全部物品，`take fruit` 等拾取单件并记录标准物品 ID。
- 中文名和英文名都能用于 NPC、物品和常用命令。
- 第一年度可选择战斗、攀爬或观察路线，完成后显示试玩结算。
- 存档、状态、地图、背包、成就与结局收集接口均已接入主循环。

## 联调修正

- 1号动态地图保留豆豆/闪尾任务完成后的消失逻辑。
- 4号物品别名统一转换成标准 ID 后再设置拾取旗标，避免重复拾取。
- 4号主循环支持 3号裸数字 NPC 选项、闪尾邀请及香蕉选项的优先路由。
- 2号主线在玩家抵达目标房间后自动触发，不必再手动输入 `investigate`。
- 5号读档完成后调用 3号 `syncLegacyFlags` 补录旧成就和结局。

## 验证结果

以下测试在 Visual Studio 2022 下全部通过：

- 1号地图测试
- 2号事件测试
- 3号 NPC / 战斗 / 收集测试
- 4号玩家与背包测试
- 5号状态、存档和结局测试

第一年度的观察路线、野蜂战斗路线、物品别名、存档与读档另做过命令行冒烟测试。
